# JNM Staff Attendance downloads

Official Android APK distribution for JNM Staff Attendance.

Download versioned APKs from Releases. Verify SHA-256 against the SHA256SUMS
asset for the same release. Android updates must retain the installed app signing
identity. Android may require permission to install from this source.

This repository contains download information and public release assets only.
Application source code and private credentials are not published here.
